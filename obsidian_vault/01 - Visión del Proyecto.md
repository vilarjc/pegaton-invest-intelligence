# Visión del Proyecto: PEGATON INVEST INTELLIGENCE

## 🎯 Visión General
Crear un sistema autónomo de inteligencia de inversión que combine análisis macroeconómico profundo y análisis técnico avanzado para generar señales claras de compra/venta en tiempo real, evolucionando desde un MVP local hasta una aplicación móvil comercializable en App Stores.

## 🌟 Diferenciales Clave
- **Integración Macro-Técnica**: No solo indicadores técnicos, sino contexto macro fundamental (40/60 peso en score)
- **Arquitectura de Agentes**: Sistema de agentes especializados que colaboran como un equipo de expertos humanos
- **Escalabilidad Inteligente**: Comienza gratis y local, crece hacia infraestructura pagada solo cuando sea necesario
- **Camino a Comercialización**: Diseñado desde el inicio para evolucionar hacia un producto móvil vendible

## 📈 Evolución Planeada
```
Fase 1 (MVP Local): 
  → Python backend + FRED/Twelve Data
  → Webapp simple (HTML/JS)
  → Obsidian como centro de conocimiento
  → Acceso solo en máquina local

Fase 2 (Acceso Remoto):
  → Despliegue en VPS barato ($5/mes)
  → Acceso vía navegador en cualquier dispositivo
  → Autenticación básica de usuario

Fase 3 (Móvil):
  → APK de Android (Flutter o React Native)
  → Funcionalidad offline con sincronización
  → Notificaciones push para señales críticas

Fase 4 (Comercialización):
  → Versión freemium: básico gratis, avanzado por suscripción
  → Posible versión paga única para tiendas
  → Expansión a iOS si Android tiene éxito
```

## 💡 Principios Rectores
1. **Gratuito cuando sea posible**: Priorizar APIs y herramientas libres/freemium en etapas iniciales
2. **Robustez sobre velocidad**: Mejor correcto y bien fundamentado que rápido pero frágil
3. **Modularidad y agente especializado**: Cada componente hace una cosa muy bien
4. **Documentación viva**: Todo el conocimiento queda en Obsidian para futuro reference y posible transferencia
5. **Camino claro a valor**: Cada iteración entrega algo tangible y útil, por pequeño que sea

## 🚫 Qué No Es
- Un bot de trading automático que ejecuta órdenes sin supervisión
- Un sistema de alta frecuencia trading (HFT)
- Un reemplazo para asesoría financiera profesional personalizada
- Un indicador mágico que gana siempre (enfocado en probabilidad y gestión de riesgo)
